The legacy base/SRCbuilder offset and separate publisher-previous provenance are unchanged. Source dispositions are preserved and exposed; this profile does not discover new dispositions or run MetamorphoSys.

The two generator modules travel with the frozen worker. Generation inputs and the actual execution dependency manifest must agree, and modified recipes, missing inputs, changed files or changed modes fail verification.
