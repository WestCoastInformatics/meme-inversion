# Read-only deployment inspection candidates

The next NCIt state-capture step needs deployed evidence, rather than another inferred database snapshot. This follow-up reviewed only primary code in `WestCoastInformatics/UMLS-Terminology-Server@708f088babd3e5d16016ab9016af9fee01f2921b`. This follow-up performed no live application, database, server or cloud operations. These findings refine the [backend discovery](nci-backend-state-discovery.md); they do not clear any [v2 capture blocker](nci-backend-preflight-v2.md).

## Identify the actual build

The packaged `app/appConfig.js` embeds Maven `${project.version}` through WAR resource filtering. Inspecting the deployed asset can establish its Maven label. That label alone cannot prove which Git commit or bytecode is deployed. Retain the actual deployed artifact identity and build provenance separately. [Configuration asset](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/rest/src/main/webapp/app/appConfig.js#L1-L11), [WAR packaging](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/rest/pom.xml#L182-L204).

## Establish active configuration and project assignment

`ConfigUtility` resolves `label.prop`, then JVM property `run.config.<label>`, with classpath/local fallbacks. Inspect only the selected path and required nonsecret settings. A configuration file present on disk does not prove its values are active: `MetadataServiceJpa` caches its terminology-handler map and selects an exact terminology handler or `DEFAULT`. Startup/reload evidence and actual retained response behavior are needed. [Configuration selection](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/model/src/main/java/com/wci/umls/server/helpers/ConfigUtility.java#L221-L318), [cached handlers](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/jpa-services/src/main/java/com/wci/umls/server/jpa/services/MetadataServiceJpa.java#L86-L108).

The supported `GET /project/{id}` getter returns the selected project. The model supplies terminology/version, branch, precedence-list assignment and automation state. Capture the actual selected project's values; do not infer them from source abbreviation `NCI`. Reading automation state does not freeze the project or stop every writer. [Project getter](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/rest/src/main/java/com/wci/umls/server/rest/impl/ProjectServiceRestImpl.java#L273-L297), [project model](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/jpa-model/src/main/java/com/wci/umls/server/jpa/ProjectJpa.java#L578-L594).

## Establish one coherent state boundary

Existing operations deserve inspection before inventing another backup mechanism, but they are not ready-made capture commands. The reviewed `refresh_rds.csh` restores using latest restorable time rather than an explicitly selected historical capture. The reviewed `sleep_rds.csh` creates a final snapshot while deleting its selected database. It must not be used as a convenient read-only export helper. No such script was run here. Inspect existing backup/restore records for exact state identity and corresponding index provenance first. [Restore operation](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/config/prod-nci-meta/src/main/resources/bin/refresh_rds.csh#L25-L39), [snapshot/delete operation](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/config/prod-nci-meta/src/main/resources/bin/sleep_rds.csh#L32-L41).

The reviewed service lifecycle creates an entity manager per service instance; its transaction helpers work inside that instance. This does not establish a snapshot shared across independent REST requests or synchronized Lucene state. A sequence of matching timestamps or before/after counts is insufficient proof of a common state. [Service lifecycle and transactions](https://github.com/WestCoastInformatics/UMLS-Terminology-Server/blob/708f088babd3e5d16016ab9016af9fee01f2921b/jpa-services/src/main/java/com/wci/umls/server/jpa/services/RootServiceJpa.java#L193-L280).

The concrete next inspection should therefore retain the deployed artifact/build identity, selected nonsecret handler configuration and activation evidence, actual project assignment, and a supported exact database/index or exporter consistency boundary. Only then should a real capture profile be enrolled and checked against preserved raw exports. Historical replay continues to use its already-preserved inputs; it does not depend on completing this new operational capture work.
