# NCIt core code package

This is the release-independent Git home for the executed NCIt core/preparation closure. `provenance.json` ties the package to the verified production-derived stable engine (`bfda2ce`). Historical source-folder snapshots and the original generated-configuration engine (`2a22938`) remain unchanged in Git.

The current producer reads ordered subsource additions and explicit new-termgroup bindings from generated data. It emits the characterized SRC records in their original allocation position, including no records when additions are empty. Existing conversion branches are retained; long new source names and term types use the reviewed bindings. The three preparation scripts retain their previously verified bytes and declared native filename arguments.

`nci.cfg.in` retains the captured effective settings. `metadata-policy.json` contains named source/termgroup definitions and reviewed publisher vocabulary, with provenance to the preserved preparation metadata. It is a representation catalog, not evidence of installed NCImeta roots. The reviewed `inputs.source_plan` selects first-release additions and explicit rankings. The generator produces read-only settings, metadata and plan files at the normal server paths. No prior release executable is copied.

See [source-plan behavior, findings and validation](../../docs/inversion-review/nci-source-plan.md). The common historical cases remain separately pinned; operational eligibility and upstream acquisition remain later gates.
